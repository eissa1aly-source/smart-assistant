# 🤖 مساعدك الذكي - Smart Assistant

مساعد ذكي متعدد اللغات مع ترجمة فورية بين العربية والإنجليزية والصينية.

## 🌟 المميزات
- 💬 محادثة ذكية بالعربية (اللهجة المصرية)
- 🌍 ترجمة فورية بين 3 لغات
- 📱 تصميم متجاوب للجوال والتاب والكمبيوتر
- 🔄 يتذكر المحادثة (Session-based)
- 😍 إيموجي تفاعلي

## 🚀 رابط التطبيق
[افتح المساعد الذكي](https://eissa1aly-source.github.io/smart-assistant/)

## 🛠️ التقنيات المستخدمة
- **n8n** - منصة الأتمتة
- **Groq AI** - نموذج الذكاء الاصطناعي (Llama 3.3)
- **HTML/CSS/JS** - واجهة المستخدم
- **GitHub Pages** - الاستضافة

## 📱 للاستخدام على الموبايل
- افتح الرابط من متصفح الموبايل
- أضف للشاشة الرئيسية عشان يشتغل كتطبيق
